## Features

> `go get github.com/pardnchiu/go-bot` · [Documentation](./doc/doc.md)

- **Synchronous reply contract** — Register one `Reply` handler per platform; a non-empty return value replies to the triggering message, and the library recovers handler panics without dropping the connection.
- **Platform-native transports** — Telegram long polling and the Discord Gateway connect outbound and run behind NAT, while LINE uses a built-in signature-verifying webhook server, all under the same `New`/`Start`/`Close` lifecycle.
- **Interactions flow back to one handler** — Telegram inline keyboards and ForceReply plus Discord select menus and the button-to-modal flow deliver user picks and answers to the same handler as `Input`.
- **Debounced "thinking" status** — `SendStatus` reacts to the source message and edits a single status message at most once per second, and `FinishStatus` clears both the reaction and the message to stay within platform rate limits.
- **Capped media persistence** — Attachment downloads enforce 20/25/50 MiB per-platform caps and write atomically under UUID filenames, while uploads stream straight from disk.
